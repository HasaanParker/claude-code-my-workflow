# `analyses/05_advisor_reframe/` — Predict-and-compare reframe (parked)

**Status:** spec only — parked as a **side deliverable**, not a committed chapter.

A methodologically different framing suggested by the advisor: instead of
estimating a US↔China aid correlation directly, fit a **pre-China baseline
model** of US aid allocation (M0), use it to generate counterfactual predictions
of where US aid "should" go, and infer China's contribution from the
**M0-vs-M1 predictive gap**. See [`SPEC.md`](SPEC.md) for the full capture.

This is an open exploration, not a decided design. It lives here until it either
graduates into a dedicated chapter or is set aside. See the decision record:
[`quality_reports/decisions/2026-06-15_advisor-reframe-parked.md`](../../../quality_reports/decisions/2026-06-15_advisor-reframe-parked.md).
